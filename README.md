# ЖК «Райки» — информационный сайт

Сайт для жителей дома по адресу Пенза, ул. Ключевая, 99 ([2ГИС](https://2gis.ru/penza/geo/70030076196447523)):
объявления, важные телефоны, полезная информация, карта.

Сайт статический (HTML + CSS + JS): ему не нужны сервер и база данных.

## Как добавить объявление или изменить контакты

Всё содержимое лежит в одном файле — [`data/content.js`](data/content.js).

1. Откройте файл на GitHub и нажмите ✏️ (Edit).
2. Скопируйте блок объявления `{ ... },` в начало списка `NEWS` и поменяйте дату, категорию, заголовок и текст.
3. Если нужно, обновите `LAST_UPDATED`.
4. Нажмите **Commit changes**. Сайт обновится через минуту-две.

Категории: `important` (Важное), `utilities` (ЖКХ), `events` (События). `pinned: true` закрепляет объявление сверху.

## Публикация (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → выберите ветку и папку `/ (root)` → Save.
Сайт будет доступен по адресу `https://<пользователь>.github.io/Raiki/`.

## Локальный просмотр

Просто откройте `index.html` в браузере.
